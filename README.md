# レシピトッテ — official website

Public marketing website: https://shiba6v.github.io/recipe-page/

This repository contains only website HTML, CSS and publicly released App Store images. The application source code is maintained separately.

## Publishing

GitHub Pages serves the `main` branch at `/` (root). No build step or dependencies are required. `.nojekyll` preserves the static files.

## Editing

Edit `index.html` and `site.css`. Update the canonical URL, sitemap and structured data when changing URLs or app information. 

Support, privacy and terms remain at their existing URLs. This website does not include analytics scripts.

App Store screenshots and app icons belong to their respective rights holders. No open-source license is granted by this repository.
